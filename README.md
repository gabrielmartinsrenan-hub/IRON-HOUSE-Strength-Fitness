# IRON HOUSE — Gym Website

A bold, responsive gym website template built with HTML, CSS and vanilla JavaScript. All visible website copy is in English.

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or run it with the Live Server extension.

## Customize before publishing
- **Gym name and logo:** search for `IRON HOUSE` and `IH` in `index.html`.
- **Contact:** replace `hello@example.com` in `script.js` with the gym's official email.
- **Memberships:** update sample prices, benefits, terms and cancellation details in the Membership section of `index.html`.
- **Programs and schedule:** replace the sample program copy with the actual services and class schedule.
- **Images:** replace Unsplash URLs with photos you own or are licensed to use.
- **Colors:** edit `style.css`; the main accent color is `#c5f05a`.

## Included
- Responsive desktop and mobile layout.
- Mobile navigation menu.
- Hero section and gym statistics.
- Training program cards.
- About section.
- Three membership plan cards.
- Contact link and footer.

## Notes
This is a front-end presentation template. It does not include member registration, subscriptions, booking, payment processing or a database. Add a secure backend and payment provider before using it to sell memberships or collect member information. All prices, features, statistics and business details are placeholders and should be verified before publication.
